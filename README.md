# Ishtar Gate

A threedimensional visualization of the storied Gate of Ishtar.

Made with Threejs.
## Summary

A fork of [GIOdeBrito/ishtar-gate.github.io](https://github.com/GIOdeBrito/ishtar-gate.github.io). It's an interactive Three.js view of the Ishtar Gate of ancient Babylon.

## What's inside

- `index.html`: the viewer page.
- `public/`: the models, textures and scripts.
- `Dockerfile` and `docker-compose.yml`: an optional container setup for serving it.

## How to view it

Serve the folder with any static web server (for example `python3 -m http.server`) and open `index.html`, or run `docker compose up`.
